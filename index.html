Optional: AI overview for bonus info, with your own Google Gemini key

Off by default. The AI overview is bonus info on top of the gambit analysis in advanced mode. With a key, each front gets an "Ask Gemini" button that sends that front's analysis (its numbers and reasons) to Google's Gemini API and shows the reply, labelled as AI-written. On top of each overview the page adds a Major Order note, taken from the order itself: if the order wants another front right now, it says to focus there, and the normal overview of the front you asked about follows. The page's own analysis never depends on it.

  • Get a key at aistudio.google.com/apikey. Google's free tier has daily limits.
  • The key is kept in this browser's local storage, on this device only. It is sent to generativelanguage.googleapis.com and nowhere else, and only when you press an Ask button.
  • Anyone who can use this browser profile can read it. On a shared computer, use "Forget key" when you're done.
  • Nothing about you is sent, only public war numbers. On the free tier Google may use what is sent to improve its products.
  • AI text can be wrong or made up. Check it against the numbers on the page.

    How is this worded?

    The page works out these tasks by itself from the game's data and names the enemy faction, not the exact enemy, so a task can be worded wrong. The online version at mrhamster112.github.io/DropIntel is corrected by hand; a downloaded (offline) copy only has the corrections made before it was downloaded.
